# XOLОDИЛЬНИК — demo landing

Демо-сайт для презентации услуги разработки сайта бургерной.

## Что уже есть
- адаптивный mobile-first дизайн;
- меню с фильтрами;
- корзина;
- демо-сбор заказа;
- оригинальные изображения меню в модальном окне;
- ссылки на Instagram и 2GIS;
- адрес: ул. Зейнуллы Жаркынбаева, 1, Кызылорда.

## Что заменить перед реальным запуском
1. Номер WhatsApp в `app.js` и кнопку заказа.
2. Логотип/фирменные изображения.
3. Точный график работы и адрес, если у заведения есть другой филиал.
4. Реальные фотографии блюд вместо превью, вырезанных из меню.
5. Подключить домен/хостинг и, при необходимости, админку.
